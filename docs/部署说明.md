## 怎么重新部署

### 1. 构建发布目录

```bash
node tools/build-dist.js
```

产出 `dist/`，只含 9 个文件。不带 `tools/`、`docs/`、`minigame/`、`.git/`
—— 那些不该上线（测试脚本体积大，且会暴露内部实现）。

### 2. 发布

通过「应用发布」能力发布 `dist/` 目录。

★ **重新发布会覆盖现有链接** —— 别人已经打开的链接会看到新内容。
想下架要走「应用管理」，不要直接删目录。

1. 用**微信开发者工具**打开 `minigame/` 目录

3. 上传代码包到微信后台

代码已经准备好（`tools/build-minigame.js` 可重新打包，`build-minigame.js` 会校验
`game.js` / `game.json` / `project.config.json` 三个配置文件）。

### 小游戏端已完成的优化（V15 伪 3D）

等距俯视斜角呈现，与 H5 版**手感对等**：

- 工位 = 立方体，忙碌时更高（高度即状态信号）
- 顾客沿斜边排队，带椭圆阴影
- 深度排序用插入排序 + 复用数组（单帧 0.072ms，稳态零分配）

**这部分只有在小游戏端能验证** —— H5 是 DOM 渲染，没有伪 3D。
